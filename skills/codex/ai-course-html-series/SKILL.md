# AI 課程 HTML 系列

系列基準是使用者指定的第一主題「ChatGPT 功能介紹」，不是任意選用最新一份 HTML 的樣式。新主題沿用白底、粉紅重點色、黑色細框手機、左側層級目錄、上方選項和右側說明；使用者後續指示優先。

## 開始工作

1. 讀取 [系列基準](references/baseline.md)，確認目前任務是修改既有教材或建立獨立主題。
2. 修改既有教材時，先查看自己的模板、資料與產生器；做可回復備份，修改來源後重新產生 HTML。不要只改生成檔而讓下次生成覆蓋掉。
3. 新主題在自己的目錄建立可單獨開啟的 HTML。圈選版可複製 [模板快照](assets/series-template.html)，依基準文件處理其中的第一主題特例。對話版使用 [對話版樣板](assets/conversation-template.html) 與 [產生器](assets/build-conversation.py)，適配方法見 [對話教學](references/conversation-guide.md)。

使用者只要求系列一致時，不擅自重寫其他主題、上傳 Notion 或替換已發布版本。無需為本機可逆編修另外要求批准。

## 教學與介面原則

- 說明先講「這是什麼、可以做什麼」，用功能真名，例如「語音對話」，不用「聲波」代稱功能。來源以支持該功能的 OpenAI 官方文章為準；手機系統操作另標示。
- 教學說明也採口語短句，例如「先把想問的丟給它，想到什麼再補充就好。」手機標題只留 ChatGPT，不加「示意」徽章。
- 學員可照說的句子要像人講話：「幫我放進行事曆，前一天提醒我。」先交代，再補充、追問、修改、核對，不把所有限制塞進第一句。
- 保留真實截圖與原始對話紀錄。改寫稿與實拍用「簡化版對話／手機真實畫面」等簡短標籤區分，不假稱改寫稿是新實測。製作過程與來源限制放資料檔或作者紀錄；學員頁面不要再加「關於這段示範」「不是重新實測逐字紀錄」等長提示，也不反覆提醒虛構素材。必要的功能使用條件在相關步驟簡短說明。
- 目錄、頁面選項、上下頁使用一致的教學順序；同範圍內容可以合併。返回要回到剛才的畫面及選取項目，而非固定首頁。
- 熱區維持透明，僅在滑鼠指向單一目標或主動開啟顯示時，用熱區內側細框提示，不用半透明底色壓暗原圖文字，不加會蓋字的原生 title 提示。目前選取的熱區不另画第二圈，只保留 SVG 圈選；鍵盤聚焦選取熱區時改變該圈顏色。圈選不填色；寬矩形採小圓角，避免切到四角的圖示與字。
- 返回首頁使用房子圖示加可見文字「回到首頁」，不要只留圖示。桌機說明卡固定對齊手機螢幕頂端，切換功能不隨圈選上下移動；窄螢幕仍放在手機下方。連線必要時在手機與說明卡間的空白處轉折。
- 選項在手機圖上方。圈選精準包住目標，不壓文字或鄰近符號；可見圈線在不碰鄰近熱區／障礙／螢幕框的前提下，保持原中心向外最多留 3 CSS px，實際熱區不擴大；連線除了避開既有功能框，也須避開截圖中未做教學按鈕的圖示與文字；用來源座標記錄避讓範圍，走不遮擋功能的最短路徑，避免繞手機外側一大圈。
- 圓角貼齊真正螢幕，外框為 3 CSS px、手機可見寬度最多 330px，放在 #f6f7fa、24px 圓角、28px 內距的底板；620px 以下上下排列、底板內距 18px。手機及說明兩欄置中，說明最多 460px。不要靠模糊整張圖掩飾裁切；保護個資且避免截入游標。
- 模擬手機以實拍螢幕的長寬比等比例呈現。這份使用入門採 384:821；高度由寬度推算，不以 svh 上限單獨壓低高度。短視窗允許整頁捲動；手機內只捲動對話區。
- 對話版右欄依序說明「這一步在做什麼？」、「換你做」、「看回覆要注意什麼」，不要重複手機泡泡全文。真實畫面模式另外顯示 `actual_prompt` 與實際後續提問全文。
- 手機控制的動作回饋放在底板工具列保留區，1.5 秒淡出，不浮在手機影像上；未選熱區僅在直接滑鼠移入或使用者主動顯示時可見。移除截圖換頁的滾輪攔截，保留段落按鈕。
- 兩份都省略示意狀態列時間；實拍如需隱藏時間，使用獨立顯示遮罩，保留原圖與原個資遮罩。
- 對話中的圖片可點擊放大，從原縮圖位置平順展開，關閉時縮回。提供關閉鍵、點背景、Esc，關閉後回到原焦點；減少動態效果偏好下直接切換。

## 選擇教學方式

- **圈選說明／手機直接操作**：認識功能、按鈕位置。附帶模板已能直接點手機熱區，開啟已連結畫面並動畫顯示解說；保留截圖及既有圈選資料，互動欄位見系列基準。
- **對話回放**：學習怎麼說與怎麼修改。讀 [對話教學](references/conversation-guide.md)，使用已包含手機內捲動、上方切換選項和圖片放大動畫的樣板。固定頂部和輸入列，保持手機比例。
- **操作模擬**：使用者要求直接點手機操作、動畫或彈出解說時，讀 [互動 iPhone](references/interactive-iphone.md)。保留系列外觀，逐個教學情境加入互動。

- 真實操作查核若發現開關與調整入口分成兩步，教材須保留中間畫面；使用對應開關初始狀態的實拍，不把用途關聯當成直接跳轉。原截圖留存，實測時間與路徑寫在作者紀錄。

- Notion 嵌入教材的頁內導覽使用 button 切換，不用帶 href 的錨點，避免 Notion 將點擊攔截成外部連結確認；保留選取狀態、鍵盤操作與返回。

## 完成檢查

先跑與變更相關的語法、資料與導覽檢查，再實際查看桌機及手機寬度的渲染：層級、選取狀態、圈選、框線、遮罩、文字換行、返回。新增操作則點完進入、關閉、返回及重播；確認手機內捲動與整頁捲動正常。

尊重工具的存取限制，不為開啟被拒絕的頁面改用繞行方式。未能實際渲染時，交付檔案並明確說明「已完成靜態檢查，視覺檢查尚未完成」。檔案生成、上傳成功都不等於視覺驗收完成。
