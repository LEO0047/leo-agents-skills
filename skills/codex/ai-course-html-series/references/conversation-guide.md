# ChatGPT 使用入門：對話版

2026-09-11 使用者確認的調整，適用同系列對話教材。整體品牌與層級仍以第一主題為基準；本文件記錄對話教學特有的互動與文案。

## 要保留的教學樣式

- 每個主題是獨立 HTML、資料和素材，與功能介紹分開。
- 以一件生活任務串起對話：看懂通知 → 補背景 → 追問 → 建立行程 → 修改 → 核對。新案例不必硬湊六回合。
- 提問和教學說明都用自然口語，例如目的可寫「先把想問的丟給它，想到什麼再補充就好。」每句提問短，允許省略已知背景，例如「這張通知，我要做什麼？」「幫我放進行事曆，前一天提醒我。」「改時間了，幫我改原本那筆，提醒照舊。」不要列角色設定或塞滿限制。
- 「簡化版對話／手機真實畫面」及本回合的畫面選項在手機上方。原始照片仍可切換查看，預設使用可捲動的 HTML 對話。
- 狀態列、工具列、輸入列固定於手機框內，中間訊息獨立捲動；切換回合定位到當前回合。
- 左欄用情境名稱作為摺疊分類，步驟編號 1–N；工具列顯示「第 X 步 / N」。返回保留模式、手機捲動與整頁捲動位置；各教材使用獨立 history key。
- 右欄用系列白底粉線卡片，依序呈現「這一步在做什麼？」、「換你做」、「看回覆要注意什麼」。手機目前的使用者泡泡以粉色外框標示，不在右欄重複同一句。
- 切到手機真實畫面時，在圖說下方呈現實際提問與實際後續提問全文，避免只能讀被截斷的截圖。
- 模擬手機右上角省略與教學無關的假訊號、電量字元；不加入 `▮▮▮ ▰` 這類裝飾。時間也省略，與功能版一致；手機標題旁不加「示意」徽章。
- 外框使用實拍螢幕比例，這份為 384:821，330px 寬時高度約 706px。不能保留 330px 寬卻用 max-height:76svh 把高度壓成 490px。需要縮小時，寬高一起縮；通常讓整頁自然捲動即可。
- 對話頂部在已向下捲動時顯示 24px 白到透明漸層；有前文的回合首次進入，顯示一秒「↑ 前面的對話」。不在沒有前文時顯示假提示。
- 通知縮圖和通知原圖都能點擊放大，約 240ms 從原位置展開；關閉縮回，支援關閉按鈕／背景／Esc、焦點還原與 reduced-motion。放大圖片依可用視窗等比例容納，不裁切通知。
- 不在學員介面增加製作過程的長篇提示。保留簡短模式標籤即可。資料與作者紀錄保存真實性、來源和測試條件，不改寫歷史來配合教材短句。

## 可重用檔案與適配

將 `assets/conversation-template.html` 複製到新主題目錄，命名 `對話版樣板.html`；將 `assets/build-conversation.py` 複製為 `製作對話版.py`。建立自己的 `對話資料.json`、`素材/`、`截圖/`。

產生器只使用 Python 標準函式庫，執行 `python3 製作對話版.py`，會嵌入本目錄素材並生成單一 HTML。修改產生器的輸出檔名及模板中的網頁標題、情境名稱、副標、historyKey 和頁尾日期，讓它們符合新主題；不要把第一份教材的日期當模板常數。

### 資料形狀

根節點為 `{ "steps": [...] }`。每個 step 包含：

- 必填 `id`（唯一字串）、`title`、`purpose`、`practice_prompt`、`watch_for`、`display_prompt`、`demo_response`。前三個分別給目的、可套用句型和核對重點；後兩個只呈現在模擬手機裡。
- `demo_response` 用換行分段，`• ` 開頭的行呈現為清單。
- 選填 `demo_followups:[{prompt,response}]`，表示同回合確認或補充。
- 選填 `asset`：相對 `素材/` 的圖片檔名；`capture`：相對 `截圖/` 的主實拍圖；`additional_captures`：其他實拍檔名陣列。支援 PNG／JPEG／WebP。可用 `asset_display` 指向另外整理的教學展示圖（支援自製文字 SVG）；仍保留原本 `asset` 與原檔，用來追溯研究素材。不要覆寫有缺字的原圖再稱為原始紀錄。
- `actual_prompt` 和 `followups:[{prompt,...}]` 用於真實畫面模式下的完整輸入文字。實際回答與測試條件保留原有欄位；不要用 `display_prompt` 或簡化回覆覆寫原文。

產生器注入 `asset_data`、`capture_data`、`gallery_data`；模板用 `__GUIDE_DATA__` 接收序列化資料。不手動複製巨大 base64 到教學資料來源。

模板已包含原生 dialog 圖片預覽和動畫，不需要另裝圖片燈箱套件。目前示範以活動通知命名附件；換題材時同步修改 alt、按鈕名稱和「查看通知原圖」文案。截圖裁切的 384/821、左右 8px、頂部 38px 是原圖參數，換截圖尺寸時重新量測。

## 驗證狀態與檢查

技能收錄時，生成、JavaScript 語法、資料保留、元素 id 與連結檢查已完成；新樣式、比例與放大動畫未完成瀏覽器實看，不把樣板視為已通過所有裝置驗收。

可渲染時檢查至少一個桌機和一個窄視窗：外框高度／寬度約為 821/384，視窗變矮時比例不變；手機內捲動、回合切換、圖片放大關閉、關閉後焦點及捲動位置正確。已有資料不得因 UI 修改而改變。

- 手機頂部僅顯示 ChatGPT，不加「示意」小標籤；上方「簡化版對話／手機真實畫面」已區分呈現方式。

- 本份目錄標題「收到通知，把事情安排好」維持單行：桌機左欄 240px、左右內距 24px／12px，保留 14px 字級和完整文字。850px 以下使用既有下拉目錄。新主題依標題長度配置，不用縮小字或截斷省略來硬塞。
