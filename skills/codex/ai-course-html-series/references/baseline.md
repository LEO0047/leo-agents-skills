## 圈選版資料與生成

模板中的 `__PAGES__` 替換為 JSON 陣列；將圖片轉為 data URL 可生成可攜的單一 HTML。序列化時將 `<` 轉成 `\u003c`，避免文字中的 script 結束標籤破壞內嵌資料。

每頁必要欄位：

- `id` 數字，`title`，`group`，`image`，`width`，`height`，`masks`（空陣列亦可），`note`，非空 `items`。
- `items` 每項：`label`、`text`、`box:[x,y,w,h]`；可選 `shape:'circle'`、`go` 目標頁 id、`jump_label`、`basis`、`sources:[{title,url}]`。
- 一個主題有上下捲動的多張圖時，可用 `views` 儲存不同畫面，item 的 `screen` 指向對應 key。別為每張相似截圖重複新增教學章節。
- page/view `obstacles:[{label,box:[x,y,w,h]}]`：畫面中未列為教學按鈕、但連線也必須避開的文字或符號。例如搜尋列關閉、分享、未標記的麥克風和送出圖示。以實際來源圖核對座標，不把既有 item 清單當成完整障礙清單。
- masks 每項 `[x,y,w,h,color]`；所有 box/mask 座標依原始圖片尺寸，縮放時同比例換算。
- 頁面陣列順序決定上下頁；左目錄與下拉選單從同一順序選出主要入口。id 不要為了排序而重編。

### 複製模板後要適配的既有特例

1. 改頁面 title、h1、副標、footer、`stateKey` 為本份教材專用值。
2. `resolveTarget` 裡的舊頁 27→26 是第一主題歷史相容規則；新教材移除這個特例，既有教材則保留其舊網址相容需求。
3. `renderScreen` 裁切視窗的 edge=8、top=38、bottom（872px 高圖為 9，其餘 8），以及 `draw` 的狀態列障礙區，都是原始截圖的幾何參數；按新圖量測，不可一律照抄。原座標畫布保留在裁切視窗內，連線以其相對 scene 的實際位置計算。
4. `按鈕`／`畫面`／`iPhone 實際畫面` 改成當前教學模式的正確描述。重建介面不能標示實拍。
5. OpenAI 來源連結只用於真正的 OpenAI 網域來源；Apple／手機系統操作依來源命名，不能統一假稱 OpenAI。
6. 新主題保留自己的資料、模板、產生器和素材；不依賴第一主題的本機路徑。既有產生器可以沿用，不為統一樣式另建複雜框架。

這是圈選版起點。對話版或互動版沿用視覺層級，替換手機內部渲染，不硬套每頁都要 box、連線和按鈕編號。


## 手機直接操作（2026-09-11）

模板已加入可直接套用的熱區按鈕、畫面切換、說明出現動畫、區域展開動畫，以及本機開關／單選狀態。既有 `box` 自動轉成透明 button；上方功能列仍只切換說明。手機內點擊則依 `interaction` 或 `go` 執行；沒有示範結果的控制顯示用途說明。

新資料可選：

- page `panel:{rect:[x,y,w,h],enter:'left'|'up'}`：只動畫該面板區域。動畫複本會保留 `masks`；不能直接顯示無遮罩原圖。
- page/view `presentationMasks`：與原始 `masks` 分開的顯示遮罩；例如隱藏狀態列時間。轉場複本也要套用，原圖不改。
- page `continuation:{up:pageId,down:pageId}`：同一長清單的上下段；段落按鈕與手機內觸控滑動共用這些目標；不接管滾輪換頁。
- item `interaction:{type:'back',fallback:pageId}`：有歷史時回上一個操作，直接開頁時回備用入口。
- item `interaction:{type:'go',target:pageId}`：教學畫面轉場；原本 `go` 仍有效。
- item `interaction:{type:'toggle',initial:true,rect:[x,y,w,h]}`：顯示並切換示意開關。
- item `interaction.viewRects`：同一開關也出現在其他截圖時，可按 view id 指定該圖上可核對的開關範圍。點擊留在當前 view，圈選用可見範圍；返回／重載保存 view，明確換功能時才重設。
- item `interaction:{type:'radio',group:'permission',value:0,initial:2,rect:[x,y,w,h]}`：同頁同 group 共用單選狀態。

rect 與 box 使用同一原圖座標系統；只為實際看見、能核對初始狀態的控制加開關或單選動作。切換留在教材記憶體，不代表改動真實帳號。未截取的登入驗證、拍照結果等仍以用途說明處理，不虛構完成結果。

第一主題的設定資料維護在 `互動設定.json`，由自己的產生器合併到頁面資料；移植時按新主題建立對應資料，勿照搬頁碼。瀏覽器實際渲染仍待確認；DOM 行為與幾何檢查不等於視覺驗收。

## 互動與美觀調整補充

- 控制列統一：翻頁為 40px 圓形按鈕、18px SVG；返回 13px、至少 40px 高；膠囊選項 14px、至少 40px 高。620px 以下返回 12px、膠囊 13px。
- 「顯示可點位置」「回到 ChatGPT 首頁畫面」放手機底板工具列；操作提示留在底板下方。動作回饋在底板上方工具列的保留空間停留 1.5 秒後淡出，不擠進解說卡。
- 所選圈線只呼吸一次（1.2 秒）；hover 僅顯示單一未選熱區的內側細框，全部熱區須由使用者主動開啟；內部透明，不加原生 title 浮動文字。減少動態效果下取消動畫。
- 功能頁程式聚焦標題時不畫外框，真正的按鈕／連結仍保留鍵盤焦點。來源截圖未提供的開關狀態或完成結果不杜撰。
- 補拍與渲染驗收記在 README，不能把 DOM／幾何檢查當作已看過畫面。

## 圈線留白（2026-09-11）

## 功能介紹的精簡目錄

第一主題採五類：安裝與登入、開始聊天、照片與檔案、更多功能、設定。目錄與手機下拉選單只列 19 個主要入口，保留全部原頁；補入思考中間步驟後共 52 頁／224 項與原頁碼；細節頁由手機互動、下一步或翻頁進入。page.navEntry 指向所屬入口，入口本身指向自己；省略時仍以本頁為入口。進入細節頁時，入口使用 aria-current=location，頁面標題仍顯示實際所在頁。設定下以 navSection 分成帳號與個人化、安全與資料兩個小標題，不再添加一層摺疊。這是第一主題的資訊架構，不要求其他主題也有五類或 19 個入口。
