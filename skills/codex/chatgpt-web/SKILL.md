# 網頁版 ChatGPT

Leo 於 2026-09-07 指定：「如果之後要用網頁版ChatGPT請使用對話模式直接選最強的模型 排除Pro模型」。

- 用現有瀏覽器操作工具查看 chatgpt.com，選「對話」模式。
- 第一次送出內容前，打開當下模型選單，選能力最強的可用非 Pro 模型；不要直接沿用預設值。模型更新後依當時選項判斷，不把某個型號永久寫死。
- 若可調整思考強度，選該非 Pro 模型可用的最高強度。確認選取狀態後再送出。
- 「Pro 訂閱方案」與「Pro 模型」分開看：帳戶可以是 Pro 方案，禁止選的是 Pro 模型。
- 未登入、選單看不到、或無法確認模型時，先處理登入／介面問題。仍不能確認就回報，不能用未知模型跑完後當成符合要求。
- 研究測試記下實際模型、模式、思考強度與日期。先前模型未知的測試保留原狀；不同模型的結果分開記，不回填或混成同一輪。

這項偏好只規範網頁版 ChatGPT 的使用方式，不要求把原本能直接完成的任務改交給 ChatGPT，也不代表授權新增訂閱、擴大帳號權限或傳送私人資料。
